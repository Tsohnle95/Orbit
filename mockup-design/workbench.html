A few details

Workbench questions.

Orbit is being built in the open, so the mockup calls out current behavior and developing ideas separately.

Is Orbit a VS Code fork?

Orbit is an Electron and React desktop application with a VS Code-style workbench and Monaco editor. This design direction emphasizes that familiar editor experience.

Does the agent work in a separate cloud project?

The current panel is associated with the local workspace selected in Orbit. The mockups focus on that repository-first interaction.

How many agent panels are available?

The current screenshot shows one agent panel. The up-to-eight-panel Agent mode direction is still in progress and is presented separately as a concept.

Which runtime is currently enabled?

OpenCode V2 is the runtime enabled in the current app.
