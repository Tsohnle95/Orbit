A development loop with less context switching.

Orbit is designed around the repo you opened. Each step stays visible in the desktop workspace, from the first question to reviewing the resulting diff.

01

Open a repository

Choose the project folder. Orbit opens the file tree and places the agent alongside the workspace you selected.

02

Ask and iterate

Send a request, follow the streamed response, attach relevant files, and queue or steer follow-up work from the same panel.

03

Inspect the work

Use Changes to see observed edits, inspect file diffs, and return to the editor or terminal to keep moving.

Common questions

Clear about what’s shipped and what’s next.

Orbit is an active project. The mockups keep the in-progress direction visible without presenting it as finished behavior.

Is the screenshot a concept image?

No. The Orbit workbench screenshot is shown without generated UI or recoloring. The website layout and multi-session direction are design mockups.

Does Orbit support eight simultaneous agent panels today?

That capacity is the design direction for Agent mode and is still in progress. The screenshot shows the current Orbit app, not a fabricated multi-panel screen.

Which agent runtime is shown?

The current Orbit app uses OpenCode V2. The mockups focus on Orbit’s editor, repository context, live changes, terminal, and agent workflow.

Can I compare a more spacious direction?

Quiet focus gives the feature story more room while keeping the workbench’s indigo and lavender visual language.
