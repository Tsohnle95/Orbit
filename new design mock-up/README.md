# Orbit design study

Open index.html in a browser. Select a direction from the left or use **Next
direction** to inspect each workspace at full size. The sample workspace is
illustrative; this is a standalone visual exploration and does not change
Orbit's production UI.

## Directions

1. **Quiet Habitat** — sage palette, connected surfaces, close to the supplied
   reference.
2. **Control Deck** — dense graphite panels with orange instrument accents.
3. **Papertrail** — warm editorial notebook with margin-like agent activity.
4. **Shell First** — phosphor terminal as the primary workspace.
5. **Swiss Grid** — bright, strict geometry with a vermilion action color.
6. **Prism** — layered violet glass and atmospheric lighting.
7. **Workshop** — tactile charcoal tool bays with safety-orange highlights.
8. **Blueprint** — drafting grid, technical borders, and cyan traces.
9. **Stillness** — quiet near-white editor with low-chrome controls.
10. **Bloom** — soft modular color blocks and an approachable palette.
